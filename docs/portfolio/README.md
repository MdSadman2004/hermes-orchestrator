# Visual sources

`overview.png` and `overview.svg` are deterministic source-guide drawings made from the repository paths listed in `provenance.json`. They do not depict a running application, measured hardware or a fresh benchmark.

The audited source commit is recorded for traceability. The guide is static: update it when the described source paths change. Other referenced screenshots and figures, if present, are pre-existing repository assets with captions in the main README.
